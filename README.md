# Combinational-Circuits

## 📌 About the Project

This repository contains the design and simulation of basic combinational circuits using Verilog Hardware Description Language (HDL).

The objective of this project is to understand the working principles of Combinational circuits through Verilog coding, testbench development, circuit schematics, and simulation waveforms using Xilinx Vivado.

## 🛠️ Tools and Technologies

- **HDL:** Verilog
- **Software:** Xilinx Vivado
- **Simulation:** Behavioral Simulation
- **Design Type:** Combinational Logic Design
